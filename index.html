God

An assistant for each person on the team. It runs on your own Mac, keeps your memory there, and works for you alone.

curl -fsSL https://god.invertix.ai/install.sh | bash

Paste it into the Terminal app on your Mac. It takes about ten minutes.

What it does

  1. Signs you in to GitHub. The code is in the team's private repository; only members can fetch it.
  2. Fetches the code into a folder named god in your home folder.
  3. Asks your name, work mail, what you do, and your mobile number if you want to text it.
  4. Sets it up on your Mac and starts it. You click through a Google sign-in and two macOS permission prompts.

Who can install it

  • Members of the team's GitHub organisation. Anyone else is told so and nothing is installed.
  • This page and the install command hold no key, no code and nobody's data. You can read the script before you run it.

What you need

  • A Mac, with Homebrew installed.
  • A GitHub account that your team lead has added to the organisation.
Your mail, calendar and files stay on your Mac. To stop it later, run ~/god/stop.sh.
